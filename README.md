# mediGram & S-LAB — veřejný náhled

Statická prezentační verze náborových stránek pro sdílení a kontrolu vzhledu.

- [Úvod](https://majkpowa.github.io/medigram-slab-nabor/)
- [mediGram](https://majkpowa.github.io/medigram-slab-nabor/medigram/)
- [S-LAB](https://majkpowa.github.io/medigram-slab-nabor/slab/)

Formulář slouží pouze jako ukázka. Příjem přihlášek a životopisů není v této verzi aktivní.

Fotografie a loga jsou převzaté ze zdrojových webů mediGram, Aspot Clinics a Pasaż Grunwaldzki. Jejich původ je uvedený v souborech `real-photos/*/photo-sources.json` a přímo na stránkách. Font Work Sans se poskytuje s původní licencí SIL OFL v `real-photos/medigram/fonts/OFL.txt`.
